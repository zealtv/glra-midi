# config-app-tour — prepare Bob's tour, then stop

**Needs Bob at the pad.** The unattended run ends here.

Preparation (the orchestrator, no Bob needed): write `tour.md` here with
numbered steps Bob can follow:
1. Launch the app; a look at each layer tab; edit one control of each action
   kind; save.
2. `glra-osc run` into a DAW or MIDI monitor: each event kind, both glides
   (by ear or by watching values), layer set/inc/dec, a layer key working from
   every layer, hot reload after a save.
3. The first real lighting write: pick a mode, Apply, replug, confirm; then
   restore Bob's own (`glean:k16n3-lighting` records his stock payload and the
   red X in Custom mode).
4. Orientation: each of the four, checked against the pad in hand.
5. "Readings to confirm": the eight in the goal's `instructions.md`, plus every
   `questions.md` from the stitches, each with the default that was taken.
6. "Left for you": review findings not fixed; ideas noted as later.

Update the README (usage, screenshots) and `AGENTS.md`'s opening status line.
Then `./.loom/loom.sh wait config-app-tour` and message Bob (`message-bob`).

Done when Bob has taken the tour and accepted it, or his feedback sits in lore
and has been shaped into stitches.
