# why led-driver was dropped

Bob, 2026-11-13: 'for the moment we will accept using the factory firmware led modes and continue with the app creation' (lore:2026-11-13-config-app-brief). Host-driven per-key colours and animations are not being built on stock firmware; choosing a factory mode moved to loom:config-app (lighting-modes, app-device-panel). Per-key LED control would come back only through loom:custom-firmware.
